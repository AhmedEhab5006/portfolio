# Ahmed Ehab Portfolio

Premium, production-ready bilingual portfolio built with Next.js App Router.

## Tech Stack

- Next.js (App Router, TypeScript)
- Tailwind CSS v4
- Framer Motion
- Context API (theme + language persistence)

## Features

- English/Arabic toggle with proper RTL support
- Dark/Light theme toggle with localStorage
- Premium hero with typing animation and CTA buttons
- About, Services, Skills, Experience timeline, Projects filter + modal
- Certifications, Testimonials, Hire Me section, Contact form
- Responsive glassmorphism UI with smooth interactions and gradients
- SEO-ready metadata and accessible semantic markup

## Run Project

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`.

## Customize Content

- Main data and text: `src/lib/translations.ts`
- Main UI structure: `src/components/portfolio-page.tsx`
- Replace CV file: `public/cv-ahmed-ehab.pdf`
